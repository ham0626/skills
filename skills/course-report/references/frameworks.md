# 分析框架菜单（纵深汇报骨架）

本文件供 `course-report` skill 在"阶段 2 · 角度与框架"调用。**框架不是固定套路，而是按话题从菜单里挑的镜头。** FTA / 瑞士奶酪 / 5M1E 只适用于"事故 / 失效成因"类话题（如实验安全）；其他课程要用通用框架。先读下面的"按话题选框架"，再取细节。

---

## 0. 按话题选框架（先读这张表）

| 话题类型 | 推荐框架 | 适配例子 |
|---|---|---|
| **事故 / 失效成因**（实验安全、工程事故、医疗差错、空难） | FTA + 瑞士奶酪 + 5M1E | 实验室病毒外泄、化工厂爆炸 |
| **因果 / 机制**（为什么 XX 会发生 / 有效） | 因果链 | 为什么某政策失效、某技术为何普及 |
| **历史 / 演变 / 政策演进**（法规迭代、技术变迁） | 时间线 / 政策演进 | 环保法规 30 年变迁、塑料禁令演进 |
| **两种方案 / 技术 / 地区对比** | 对比 | 煤电 vs 新能源、两国垃圾分类 |
| **政策 / 环境 / 社会议题**（环保通选课常见） | 系统图 / 利益相关方 | 雾霾治理、塑料污染、碳交易 |
| **问题 → 对策** | 5W1H / 问题树 | 校园垃圾分类推不动的根因 |

> 选框架的标准只有一条：**它能帮你在"一个点"上挖深，而不是把话题铺开。** 同一个话题也可组合（如系统图定位 + 时间线讲演变）。

## 1. FTA — 事故树分析（Fault Tree Analysis / 事故树）【事故成因类专用】

**定位**：把"某个顶事件为什么发生"拆成一层层因果，最适合"纵深一个点"的骨架——但仅限失效 / 事故类话题。

**结构**：
- **顶事件（Top Event）**：要深挖的那一个事故 / 失控（如"实验室病毒外泄感染"）。
- **中间事件**：导致顶事件的直接原因（如"气溶胶扩散到公共区域"）。
- **基本事件（树叶）**：最底层、不可再分的失效（如"灭活设备盲区""未执行双人双锁"）。
- **逻辑门**：AND（多个条件同时成立才触发）/ OR（任一成立即触发）。

**构建步骤**：
1. 先定顶事件（一句话）。
2. 追问"因为什么"向下拆 2–3 层。
3. 给每个基本事件配一个**点击弹出的小问题**（见脚手架 modal），让观众边点边想。
4. 把基本事件归类进 5M1E（见下），便于复盘"哪类防线最弱"。

**交互写法**：每个节点是可点击元素，点击 `openModal(节点id)`，弹窗显示"这个环节当时发生了什么 + 一个问题"。不要把所有因素平铺在一页，避免又变回横向。

## 2. 瑞士奶酪模型（Swiss Cheese / Reason Model）【事故成因类专用】

**定位**：解释"为什么层层防线还是漏了"——最适合放在 FTA 之后作为"防线失守"的动画层，同样仅限失效类。

**要点**：
- 每一片奶酪 = 一道防线（制度 / 培训 / 设备 / 监管）。
- 每片都有孔 = 该防线的固有漏洞。
- 事故发生在**所有孔刚好对齐**的那一瞬间。
- 区分**潜在失效（latent，制度/设计漏洞）**与**主动失效（active，人的操作失误）**。

**动画建议**：多片奶酪从错位 → 缓缓对齐，其中一片留一个空（漏洞），对齐瞬间一个 ⚠ 警告标闪烁。落脚："真实世界里没有全市沦陷，但每一次'看不见的失控'都源于防线孔洞的偶然对齐。"

---

## 3. 5M1E — 人 / 机 / 物 / 环 / 法【事故成因类专用】

**定位**：给 FTA 的基本事件做**分类 taxonomy**，让"我的深挖体现在哪"一目了然（避免被质疑"五个因素不就是一层吗"）。

| 维度 | 含义 | 示例（生物安全） |
|---|---|---|
| 人 (Man) | 操作者素质 / 遵守规程 | 防护松懈、未执行双人双锁、跨专业未受训 |
| 机 (Machine) | 设备 / 工具盲区 | 灭活设备覆盖不到的环节、通风循环 |
| 物 (Material) | 作用对象本身的危险 | 正在使用的那株活病毒 |
| 环 (Environment) | 环境 / 空间 | 实验室通风、相邻公共区域 |
| 法 (Method) | 制度 / 法规漏洞 | 条例空白、上报滞后、追责缺失 |

**用法**：把 FTA 的基本事件分别挂到 5M1E 下，纵深感来自"同一事件在五个维度同时失守"的剖析，而不是平铺五个因素。

## 4. 通用框架（任选，不限课程）

### 4.1 因果链（Causal Chain）
- 适合"为什么 XX 会发生 / 有效"。把 A→B→C→结果串成一条链，每个环节可点开深挖。
- 与 FTA 区别在于：FTA 是树状分叉（多因一果），因果链是线性主因推进，更轻量。

### 4.2 时间线（Timeline）/ 政策演进
- 适合历史 / 演变 / 法规迭代类。横轴排关键节点（年份 + 事件 + 影响），突出"转折点"。
- 环保通选课例：某类污染从"无人管"到"立法限排"的关键节点。

### 4.3 对比（Compare & Contrast）
- 适合两种方案 / 技术 / 地区。双栏或背靠背，对齐同一组维度（成本 / 效果 / 公平性 / 可持续性）。
- 纵深点 = "为什么 A 在这一个维度上优于 B"，而非泛泛罗列两边。

### 4.4 系统图 / 利益相关方（System Map / Stakeholders）
- 适合政策 / 环境 / 社会议题。画出"谁受影响、谁决策、谁受益、谁买单"，暴露系统里的张力点。
- 环保通选课例：塑料污染 = 生产端 / 消费端 / 回收端 / 监管端如何互相牵制。
- 纵深点 = 选中系统里最关键的"卡点"深挖，而不是把整张图画完就完。

---

## 5. 组合与 anchor 原则

- **组合范式（事故类）**：`顶事件(FTA) → 因果链向下拆 2–3 层 → 基本事件用 5M1E 分类 → 奶酪层解释"防线为何同时失守" → 落点回到"我们该怎么做"`。
- **组合范式（通用）**：`钩子开场 → 锚点事件 → 所选框架拆深 → 回到"我们/课程"的行动建议`。
- **anchor 事件选取原则**：必须真实、可溯源（官方通报 / 法规 / 论文 / 报告）。用流行文化（生化危机等）只作开场钩子，正文回到真实事件并标注出处。

## 6. 示例（范式演示，内容可替换）

- **实验安全**：顶事件=2004 北京/安徽 SARS 实验室感染；框架=FTA + 瑞士奶酪 + 5M1E；钩子=生化危机；来源=卫生部 2004-07-01 通报、国务院令 424 号。
- **环保通选课（示意）**：话题=塑料污染；框架=系统图/利益相关方 + 时间线；锚点=某次限塑政策转折；钩子=一条被冲上垃圾岛的海鱼；落点=作为消费者的我们能改什么。
